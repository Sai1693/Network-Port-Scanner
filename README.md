# 🔍 Network Port Scanner

A simple Python-based TCP Network Port Scanner that scans a target host for open ports using socket programming and multithreading. The project is designed to demonstrate networking fundamentals and basic cybersecurity concepts.

---

## 📌 Features

- Scan any valid IPv4 address
- Detect open TCP ports
- Multithreaded scanning for faster execution
- Input validation for IP addresses
- Automatically generates a scan report
- Simple command-line interface
- Beginner-friendly project

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/your-username/Network-Port-Scanner.git
```

Move into the project folder:

```bash
cd Network-Port-Scanner
```

Install dependencies:

```bash
pip install -r requirements.txt
```

---

## ▶️ Usage

Run the application:

```bash
python scanner.py
```

Enter a target IPv4 address:

```
192.168.1.1
```

The scanner checks ports **1–1024** and displays any open ports.

A scan report is automatically saved in the **output** folder.
